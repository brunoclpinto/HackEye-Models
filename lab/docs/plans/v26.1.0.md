## Context
`HackEye26.1-124` (17,347 frames: train 14,830, val 2,517; 1280×720 JPG, 124-class Vistas P-mode PNG masks) holds the X model's
pseudo-labels. They need two kinds of work before retraining:
1. **Correction.** Some regions are wrong (surf, foam and glare labelled "snow"; rare surfaces swallowed by road or sidewalk), and
   many boundaries are rough.
2. **Taxonomy work.** The user wants to create new classes, merge classes, expand them (undo a merge, or split a class into new
   sub-classes), and save the result as a new dataset yaml, as with the 124 → 48 merge done earlier.

CVAT is too heavy and handles dense 124-class masks badly, and the HackEye Lab belongs to the app repo's version cycle. So we're
building a separate **Models Lab** in `~/repos/HackEye-Models`. It is one tool for browsing, tagging, pixel-accurate editing
(with SAM2) and taxonomy building.

User choices (2026-10-27):
- device: Mac with mouse or trackpad;
- class picker: all 124 classes, plus any custom ones;
- SAM2: in phase 1;
- browsing: in the lab, no FiftyOne;
- "expand" means both undo-a-merge and split-into-sub-classes;
- naming: the master keeps its name (`HackEye26.1-124`), and exports are named **by hand** with a version, e.g.
  `HackEye26.1.1-<N>`. The lab never auto-names.

## Core model
- **Master dataset:** edits happen here (`/datasets/HackEye26.1-124`). Its masks store **base class ids**: the 124 Vistas ids,
  plus custom classes appended from id 124 up to 254 (255 stays "ignore").
- **The base taxonomy travels with the master** as `<root>/taxonomy.json`: `[{id, name, raw_name, hier, color, void, parent?}]`.
  - A custom class has a `raw_name` such as `hackeye--flat--curb-ramp`, and optionally the `parent` class it was split from.
  - The master yaml's `names` are regenerated from this file.
- **Merge maps are non-destructive views.** They use the format of today's `HackEye26.1-48.yaml` (merged name → member raw
  names, fnmatch globs), extended so members can be custom classes. Masks never change because of a merge, so "expand" (ungroup)
  is always possible.
- **Split:** "split class X" creates child classes with X as `parent`. Their pixels start empty and are assigned in the editor
  (brush, region relabel, SAM, polygon) or by bulk rules restricted to class X ("protect source = X").
- **Save as new dataset (export):** the user types the name and version.
  1. The lab writes the map to `taxonomies/<name>.yaml` in the repo.
  2. It builds `/datasets/<name>/` with hardlinked images and LUT-remapped masks, plus `<name>.yaml` (Ultralytics data yaml,
     `label_mapping` voids) and a manifest.
  3. It verifies the export the way `vistas_merge.py` does: every merged class's pixel count must equal the sum of its members'.
  4. It runs as a background job with progress in the UI. The lab never runs git; Opus or the user commits the map.

## Services and data safety
- **`lab`** (CPU, slim Python, FastAPI + uvicorn): `127.0.0.1:8766`, UID:GID, `restart: unless-stopped`. It mounts the repo and
  `/datasets` read-write.
  - It reuses the HackEye Lab patterns `_RevalidatingStaticFiles` and `_SelectiveGZip` (`RnD/lab/server.py:61-77`, `:777-787`)
    and its style tokens (`RnD/lab/static/style.css:1-13`).
- **`sam`** (GPU, internal only), built from the `~/media-gen/segmentation` recipe with the `~/models/sam2/sam2.1_hiera_large.pt`
  weights read-only.
  - It caches image embeddings per stem (LRU of 8), loads lazily, and frees VRAM after 10 minutes idle.
  - The lab works without it; the SAM tool is greyed out.
- **Tailscale:** `tailscale serve --bg --https=8443 http://127.0.0.1:8766`.
- **Mask edits:**
  - Written in place, atomically, as P-mode PNGs with the palette from `taxonomy.json`.
  - Validated: 720×1280, every id defined in the taxonomy.
  - The original pseudo-label is backed up once to `<root>/lab/orig/` before the first change; "Revert" restores it.
- **`<root>/lab/lab.db`** (SQLite): frame status (`todo`/`ok`/`fix`/`drop`/`edited`) and a note, an append-only edit log, and
  recounted class pixels.
  - `drop` is only a tag; deletion is a separate explicit step.
  - `datasets/hackeye/sync_lab_edits.py` syncs the `classpix` rows and re-finalizes.
- **Taxonomy safety:**
  - A custom class can be deleted only when it has 0 pixels, or after a remap target is chosen.
  - Taxonomy changes are logged in the DB and `taxonomy.json` keeps a `.bak`.

## UI (desktop, mouse first)
**1. Browser**
- Virtual grid of thumbnails, made on demand and cached in `<root>/lab/thumbs/`.
- Filters: split, clip, status, confidence, class present, edited.
- Sort by time, confidence or edit time. Keys 1–4 set the tag; Enter opens the editor.

**2. Editor**
- **Canvas:** image plus mask through an RGBA lookup table (the Lab's `MaskStyle.paint`, `RnD/lab/static/js/classes.js:84-91`;
  grid decode as in `overlay.js:236-250`).
- **View controls:**
  - `M` toggles the mask and a slider sets its opacity; `O` shows outlines only.
  - Wheel zoom goes to the cursor, from fit up to 16× with nearest-neighbour; a pixel grid appears from 8×.
  - Space-drag or middle-drag pans.
- **Readout:** the class under the cursor.
- **Class picker:** every base class (124 plus custom), with hierarchy, search, a recents row mapped to keys 1–9, and alt-click
  eyedropper.
- **View-through-map:** a toggle that previews the mask through a merge map; editing stays in base ids.
- **Tools:**
  - `B` brush, 1–64 px, round or square; 1 px square gives exact pixels.
  - `R` region relabel: click for the connected region, shift-click for every pixel of that class.
  - `L` polygon or lasso fill.
  - `S` SAM2: left-click and right-click add positive and negative points, drag makes a box, Tab cycles the 3 candidates,
    Enter applies.
  - All tools have **protect source class**, which restricts the edit to one class; this is the main aid for boundaries and
    splits.
- **History and saving:** undo and redo through bounding-box patches; `Ctrl+S` saves and frames autosave when you move on;
  `N`/`P` go to the next or previous frame and neighbours are preloaded.

**3. Taxonomy**
- **Left panel: base classes** with colour, frame presence and pixel share.
  - Actions: **Create class** (name, hierarchy, colour), **Split class** (creates children of the selected class),
    rename and recolour custom classes, and delete a custom class (only when empty, or after a remap).
- **Right panel: map builder.**
  - Start from scratch or **load** an existing map (e.g. `HackEye26.1-48`).
  - Select classes, then **Merge** (name it; the colour defaults to the largest member's).
  - **Expand** returns a group to its members. You can also mark a group void/ignore.
  - Live stats: the class count N and the pixel share per merged class. Classes left unassigned keep their own class
    (the current convention).
- **Save as new dataset:** a name field with a format hint `HackEye<yy.major.minor>-<N>` and nothing filled in.
  - Saving writes the map and starts the export job, with progress and a verify result.
  - **Save map only** writes just the yaml.

**4. Bulk rules**
- "Class A → class B" over a filter, with an optional "only pixels of class X".
- A dry run shows the frames and pixels affected; Apply backs up and logs.
- It covers the pending snow → water remap, which runs only on the user's click.

## API contract (summary; the full contract goes in `lab/CONTRACTS.md` before the workers start)
- **Frames:**
  - `GET /api/meta`, `GET /api/frames?…`, `GET /api/frames/{stem}`;
  - `/image.jpg`, `/thumb.jpg`, `/mask.png` (8-bit grayscale index PNG);
  - `PUT /mask` (index PNG body), `POST /revert`, `PUT /state`.
- **Taxonomy:**
  - `GET /api/taxonomy`;
  - `POST /api/taxonomy/classes` to create, `POST /api/taxonomy/classes/{id}/split`, `PATCH/DELETE /api/taxonomy/classes/{id}`;
  - `GET /api/maps`, `GET /api/maps/{name}`, `POST /api/maps/preview` (returns the LUT, N and stats).
- **Export:** `POST /api/exports {name, map}` starts the job; `GET /api/exports/{job}` returns its progress and verify result.
- **Rules:** `POST /api/rules/dry-run|apply`.
- **SAM:** `POST /api/sam/embed {stem}` and `POST /api/sam/predict {stem, points, labels, box}`, proxied to `sam`.
