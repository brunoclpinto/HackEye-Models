# v26.1.1: a single-page layout with permanent browse, carousel, image and work panel

Status: **shipped 2026-10-27** on branch `lab26.1` (the user said "plan, execute" and agreed the defaults). Worker: Sonnet (the frontend worker of v26.1.0). Planning,
review and integration: Opus.

User request: "browse is not a menu option, its permanent with filters at top, carroussel navigation. below we have the
image. below image we have the selected menu option work stuff. menu order is correct and defaults to edit. each group
should be collapsable."

## Layout (top to bottom, one page, no Browse tab)
1. **Header:** the title, then menu tabs **Edit | Taxonomy | Rules** (that order). Edit is the default route (`#edit/<stem>`,
   or the first frame of the filter when none is given). The `?` button stays.
2. **Browse group (permanent, collapsible):**
   - **Filter bar** as before: split, clip, status, conf, low, class with min px, edited, sort, reset, and the frame count.
   - **Carousel:** one horizontal, virtual-scrolled strip of thumbnails for the filtered list. The current frame is
     highlighted and kept centred. Each card shows the stem, conf and a status badge.
   - **Carousel controls:**
     - Click opens a frame in the image; the wheel or a drag scrolls the strip.
     - `←`/`→` (and `N`/`P`) step frames and autosave when dirty. `Home`/`End` jump to the first or last frame.
     - Tag buttons (ok, fix, drop, todo) act on the current frame.
3. **Image group (collapsible):** the editor canvas (zoom, pan, overlay, outline, grid, readout) for the current frame.
   It's shown on every tab, so Taxonomy can preview a map on the image and Rules can show a sample.
   - The height is resizable with a drag handle under the image, remembered per browser. It defaults to fitting the
     viewport.
   - When collapsed, it keeps a one-line strip: the stem, status and edits.
4. **Work group (collapsible):** the selected tab's controls, in collapsible sub-groups.
   - **Edit:** Tools (tool buttons, brush size and shape, SAM candidates) · Classes (active and secondary class, search,
     recents, the picker as compact chips grouped by hierarchy, each hierarchy group collapsible) · Protect · View
     (mask, opacity, outline, grid, view-through-map) · Frame (status buttons, note, save, revert, undo and redo).
   - **Taxonomy:** Classes (table and actions) · Map builder · Save / export. When a map is loaded, the image shows it
     through view-through-map.
   - **Rules:** Rule (from, to, filter) · Result (counts, sample thumbnails, apply, job progress). Clicking a sample
     thumbnail opens that frame in the image.
5. The status bar stays at the bottom.

## Collapsing
Every group and sub-group has a header with a chevron, and clicking it collapses or expands. The state is kept in
`localStorage` (inside try/catch) per group id. The defaults are all expanded, except hierarchy groups in the picker that
have no pixels in the current frame.

## Keys (changed)
- **Tagging:** `1`–`9` now always pick recent classes, so tagging moves to `Shift+1`–`4` (matched by `e.code`) for ok, fix,
  drop and todo. `Cmd+digit` belongs to the Mac browser (it switches tabs), so the old `Ctrl/Cmd+1–4` is dropped.
- **Navigation:** `←`/`→` step frames whenever focus is not in an input. Everything else is unchanged.
