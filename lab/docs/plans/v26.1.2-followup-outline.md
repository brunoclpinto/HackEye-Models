# v26.1.2 follow-up: the Inspect selection draws boundary lines, not a bounding box

Status: **shipped 2026-10-27** on branch `lab26.1` (the user said "go for it"). No version bump: the user called it "one correction on this
version". Worker: Sonnet (frontend). Planning, review and integration: Opus.

User request: "one correction on this version, i don't want binding box, i need boundary lines like in hackeye lab."

## Change
- **The rectangle goes. The selected item is drawn by its boundary**, the way the HackEye Lab draws an item's own mask
  contour in outline mode (`~/repos/HackEye/RnD/lab/static/js/overlay.js` `drawHazard`, the `poly` branch: a ~15% fill in
  the item's colour, a stroked contour with round joins, and the label at the contour's top-left).
- **Contours:**
  - Trace them on the selection's region bitmap along **pixel edges** (marching squares or edge tracing), so the line
    follows the mask exactly, pixel steps included.
  - Every closed contour is drawn: the outer boundary **and the holes** (e.g. a car inside a sidewalk region gives the
    sidewalk a hole).
  - Collinear edge runs are merged so the paths stay small.
  - The tracing runs once per selection and is cached; it doesn't run on every redraw.
- **Drawing (screen space, crisp at any zoom):**
  - a dark outer stroke about 5 px at about 60% alpha, then a 3 px stroke in the class colour, with round joins;
  - the ~15% tint of the region stays.
  - Where a light class colour would vanish on a light background, the dark under-stroke keeps it readable.
- **Label tag:** the same text and style as before (`<name> · id <id> · <N> px`, plus the merged name). It is anchored
  at the top-left of the contour's extent, above it, or inside when there's no room, and clamped to the canvas.
- **Everything else is unchanged:** selecting by click or tap, `Esc`, `Enter` relabel, clearing on an edit or frame
  change, touch, and the readout.

## Tests
- In `test_inspect.py`, the selection is still checked against a flood fill (id, px, bbox).
- `__lab.state().selection` gains `contours` (the number of closed paths) and `edgeLen` (total boundary length in image
  pixels). On the fixture, `edgeLen` equals the region's 4-neighbour boundary edge count, computed in Python from the mask.
- A region with a hole reports at least 2 contours.
- **Canvas sampling:** at fit zoom, the screen pixel on a known boundary edge carries the class-coloured stroke. A pixel far
  inside the region shows only the tint, with no stroke; this proves there is no rectangle.
- All other tests keep passing; the result assertions are unchanged.
