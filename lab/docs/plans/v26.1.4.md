# v26.1.4: scroll-view pan and zoom, clear the class, selected-class-only mask, numbered detections

Status: **shipped 2026-10-29** on branch `lab26.1` (the user said "go for it"). Worker: Sonnet (frontend). Planning,
review and integration: Opus.

User request: "i can zoom the image but not drag it into position, it should behave like a mobile phone scrollview where
i can zoom and drag image around to focus on specific locations; should be able to unselect selected class; when no
class is selected show all masks otherwise just the selected class mask; below selected class should show numbered list
of detections for fine-selection."

**Follow-up the same day (before shipping):** "keep zoom on mouse wheel, move image with ctrl+mouse down".

**Cause of the pan problem:** with a mouse or trackpad, an Inspect press selects at once and a drag does nothing; panning
needs Space-drag or a middle-drag, and a two-finger trackpad scroll zooms instead of moving the image. Touch already pans
when zoomed.

## 1. Scroll-view behaviour (all tools unless noted)
- **Inspect, any pointer (mouse, pen, touch):** press-drag pans the image (moving more than 6 px); a press-release
  without moving selects, on release. At fit zoom on touch the page still scrolls natively (`pan-y`, unchanged); at fit
  zoom with a mouse, a drag pans nothing (the image already fits).
- **Wheel:** unchanged, every wheel event zooms at the cursor (user, 2026-10-29: "keep zoom on mouse wheel").
- **Ctrl + mouse down (any tool):** drags the image (`Cmd` too), like Space-drag and middle-drag, ahead of the tool
  action (user: "move image with ctrl+mouse down"). The canvas context menu stays suppressed (macOS Ctrl+click).
  - `+`/`-` keys still zoom, `F` fits, `0` is 1:1.
- **Double-click (mouse) / double-tap (touch), Inspect:** toggles fit and 4× at the point.
- **Touch fling:** a one-finger pan in Inspect and a two-finger pan keep gliding after lift, with velocity decaying
  (~0.95 per frame at 60 fps, stops under 0.05 px/frame), like a phone scroll view. Any new pointer down stops it.
- **Pan limits:** unchanged (`clampPan`, 64 px of the image always visible).
- **Editing tools:** a drag keeps painting; pan with Ctrl+drag, two fingers, Space-drag or a middle-drag.
- **Help (`?`) and README** list the new mouse/trackpad behaviour.

## 2. Clearing the selected class
- The `active-class` box next to the search gets an `×` button (`data-testid="active-class-clear"`, title "Clear the
  selected class (Esc)"), at least 36 px on touch.
- Kept: clicking the active chip again, `Esc` in the empty search box. New: `Esc` on the page (focus not in an input)
  with no Inspect selection and no lasso/SAM in progress clears the class. Order of `Esc`: cancel the lasso/SAM, else
  clear the Inspect selection, else clear the class.

## 3. Mask shows only the selected class
- **No class selected:** the overlay shows every class (as now).
- **A class selected:** only pixels of that base class are coloured; every other pixel is transparent (the image
  shows through). Outline mode outlines only that class's boundaries. With view-through-map the selected base class's
  pixels are coloured with their merged colour.
- Repainted in full when the class changes (one pass, a few ms); dirty-rect repaints after edits honour the filter.
- `Mask` (`M`) and opacity work as before. The Inspect outline and label still draw for any selected item.

## 4. Numbered detections under the selected class
- **Below the head (search + selected class), only while a class is selected:** a `Detections (<n>)` row
  (`data-testid="detections"`) of compact chips `#<k> <px> px` (`data-testid="detection-item"`, `data-k`), numbered
  1..n by size, largest first (ties by scan order). Chips wrap; no inline scroll.
  - More than 60: the first 60 show, then a `+<rest> more` button that expands the full list (and `less` collapses).
  - "0 detections in this frame" when the class is absent.
- **On the image**, while a class is selected: a small number tag `<k>` at each detection's label point (the first pixel
  of the region in scan order, nudged inside the canvas), drawn in screen space like the Inspect label, for the first 60
  detections. Tags are skipped for a detection whose bbox is under 3 screen px at the current zoom.
- **Click / tap a chip:** selects that detection (same as an Inspect click on it: outline, label, `Enter` relabel) and
  centres the view on it, zooming so its bbox fills about half the view, between fit and 8×; a detection already larger
  than that just centres. The chip of the current Inspect selection is highlighted (also when it was picked on the
  image).
- **Data:** `counts.js` also returns, per class, the regions `{k, px, bbox:[x0,y0,x1,y1], seed}` sorted as above, from
  the same single labelling pass (recomputed on the same events as v26.1.3). Exposed as
  `window.__lab.state().detections` (array for the selected class, or null).

## 5. Tests
- **E2E (`test_view.py`, new):**
  - mouse: zoom in (`Ctrl`+wheel), Inspect drag pans (`state().zoom` unchanged, the image point under the start follows the
    pointer within 1 px) and selects nothing; a click without moving selects;
  - the wheel zooms with the cursor point fixed within 1 px; Ctrl+drag with Brush active pans and paints nothing;
  - double-click toggles fit and 4×;
  - touch fling: after a quick one-finger swipe and lift, the view keeps moving for a few frames, then stops.
  (Expose `vx`, `vy` in `state()`.)
- **E2E (`test_classes.py`, extend):**
  - the `×` clears the class; page `Esc` clears it when nothing else is pending;
  - with a class selected, a canvas pixel of another class shows no overlay colour (sample the mask layer through a
    `__lab` hook, e.g. `maskPixel(x,y)` returning RGBA) and a pixel of the class does; clearing restores all;
  - detections: count and px sizes equal `cv2.connectedComponentsWithStats(connectivity=4)` for that class, sorted by
    size; clicking chip `#1` selects a region whose `px` equals the largest component and whose bbox is inside the view.
- Existing tests that select with a mouse press in Inspect now select on release; adapt them.
