# v26.1.5: view colour for contrast, label size slider

Status: **shipped 2026-10-29** on branch `lab26.1` (the user said "go for it"). Worker: Sonnet (frontend). Planning, review and integration: Opus.

User request: "the class colour can stay fixed but i need to change it while editing for contrast purposes allow me to
do so in view group. in view group add a label size slidder, i need bigger labels sometimes as well."

## 1. View colour (display only)
- **View group, new control:** `Colour` (`<input type=color>`, `data-testid="view-color"`) plus `Reset`
  (`data-testid="view-color-reset"`).
  - It targets the **selected class**; with no class selected, the class of the Inspect selection; with neither, the
    control is disabled and its title says "Select a class or an item first".
  - A text hint next to it names the target (`for <name>`), and says `(custom view colour)` when an override is set.
- **What it changes:** only how the class is drawn in the Lab for this viewer: the mask overlay, outline mode, the
  Inspect outline, tint and label, the detection tags, and the class's chip swatch (picker, Detections, active-class box).
  The **taxonomy colour never changes**: `taxonomy.json`, the Taxonomy table, maps and exports are untouched, and no API
  call is made.
- **Storage:** `localStorage` key `lab.viewColors` = `{<id>: [r,g,b]}` inside try/catch; it survives reloads and
  frames, and the page works without it. `Reset` removes the override for that class. A `Reset all` button
  (`view-color-reset-all`) appears when any override exists.
- **Live:** the colour applies while dragging the picker (`input` event), with a full mask repaint (a few ms).
- **View-through-map:** the override applies to base classes only; when a map is viewed, merged colours are drawn as
  before (the hint says so while a map is on).

## 2. Label size
- **View group, new slider:** `Labels` (`data-testid="label-size"`, range 10–32 px, step 1, default 13) with the value
  shown in mono.
- Scales the Inspect label tag (font size = value; the tag height and padding follow) and the detection number tags
  (font = round(value × 0.85)). Contour line widths are unchanged.
- Stored in `localStorage` `lab.labelSize` (try/catch); applies at once (redraw).

## 3. Tests
- **E2E (`test_view_style.py`, new):**
  - with a class selected, setting the colour changes `maskPixel` of one of its pixels to the new colour (alpha as
    before) and the chip swatch background; `/api/taxonomy` still returns the original colour; reload keeps the override;
    `Reset` restores the original;
  - with no class but an Inspect selection, the control targets that item's class; with neither it is disabled;
  - the label slider changes the drawn label size: expose `state().labelSize` and the last drawn label tag height
    (`state().labelBox`, `{w, h}` in CSS px) and assert it grows from 13 to 26.
- Unit tests unchanged.
