# v26.1.6: Filters, a Frame group with a side column, hover descriptions

Status: **shipped 2026-10-30** on branch `lab26.1` (the user said "go for it"). Worker: Sonnet (frontend). Planning, review and integration: Opus.

User request: "add quick description to buttons when hovering; browse group rename to filters. move the buttons on the right
(that match frame group below image) and add it to image group right side and add a save button to it (save will save
current changes to file); remove frame group; rename image group to frame; move tools protect and view to the left of the
new frame group, max occupancy 25%; from tools remove the erase to and history + current selection history bit."

## 1. Filters (was Browse)
- The permanent top group is titled **Filters**. Its `data-gid` stays `browse` (keeps the stored collapse state and the
  `group-browse` test id). Its header keeps only the title and the frame count; the tag buttons and Prev/Next leave it.

## 2. Frame (was Image) and the side column
- The image group is titled **Frame** (`data-gid` stays `image`).
- **Header, right side:** `#eInfo` stays on the left; then, pushed right, the Inspect selection label, the tag segment
  `ok | fix | drop | todo` (`#bTags`, Shift+1-4), Prev / position / Next (`#bPrev`, `#bPos`, `#bNext`, wrap-around), and
  **Save** (`#eSave`, `data-testid="btn-save"`, primary, disabled when nothing is unsaved, Ctrl+S). Save writes the current
  edits to the master mask file (the existing `save()`; originals stay in `lab/orig`).
- **Body:** a row: the **side column** on the left (Tools, Protect, View, in that order, the existing groups moved unchanged
  apart from §4), the canvas stage and its resize handle on the right.
  - The side column is at most **25%** of the row width (`flex: 0 1 25%; max-width: 25%; min-width: 0`), the stage takes the
    rest. Controls in the column wrap.
  - The side column shows only on the **Edit** tab (these groups were edit-only before); on Taxonomy and Rules the stage
    takes the full width.
  - At `max-width: 600px` (phone) the column stacks above the stage at full width.
- The stage height and its drag handle keep working as before (the handle is under the stage, not under the column).

## 3. Frame group removed
- The old `edit-frame` sub-group goes: the duplicate status segment (`#eStatus`), the note field (`#eNote`), Undo/Redo
  buttons, Revert, and the second Prev/Next (`#ePrev`, `#eNext`). Their JS wiring is removed, guarded where shared.
  - Undo/Redo stay on Ctrl+Z / Ctrl+Shift+Z. A note already stored stays in the DB and is still shown in `#eInfo` if it was
    shown there before.
  - Revert has no shortcut, so it leaves the UI (the API stays). Question mailed to the user, default: leave it out.
- The Edit pane now holds only Classes (full width).

## 4. Tools trimmed
- `#ePickerExtra` goes: the "Erase to <class>" box and the recent-class buttons. Behaviour stays: right-click a chip still
  sets the secondary class (now shown by the chip's `sec` style), `X` still swaps, `1-9` still pick recents (no visible
  list). The help overlay and chip tooltip keep describing them.

## 5. Hover descriptions
- Every `button`, `select`, range/colour input, tab link and group toggle gets a short `title` (what it does, plus the
  shortcut in parentheses when there is one). Covers the static page and the buttons made in JS (taxonomy, rules, dialogs,
  detections, group toggles: "Collapse or expand <name>").
- E2E check: every visible `button` in each tab has a non-empty `title`.

## 6. Tests
- Update the E2E tests that used removed elements (`btn-revert` → revert through the API or drop that step; `edit-frame`
  references in `conftest.py` docs).
- New `test_layout.py`: titles (Filters, Frame); the header holds tags, nav and Save; Save is disabled when clean, enabled
  after a brush stroke, and a click writes the mask (`state().dirty` false, `/api/frames/<stem>` reports edited); the side
  column is ≤ 25% + 1 px of the frame body width on a 1400 px viewport and is left of the canvas; hidden on Taxonomy;
  no `#ePickerExtra`, `group-edit-frame` gone; every visible button has a title.
- Unit tests unchanged.
