# Milestone lab26.1: Models Lab

Status: **v26.1.0 shipped 2026-10-27** on branch `lab26.1`. It is not merged into `main` yet. After the squash-merge, delete
the branch locally and remotely.

## Scope
A tool for preparing HackEye training data from the pseudo-labelled media library (`HackEye26.1-124`):
- **Correction:** browse and tag frames, then fix masks pixel by pixel with the brush, region relabel, polygon/lasso,
  SAM2 click-to-outline and the protect source class option. Bulk class rules cover the systematic errors.
- **Taxonomy:** create classes, split a class into sub-classes, merge classes into maps, expand merges, and export
  datasets under names the user types.

The milestone ends when the corrected data has been exported and used to retrain the app model (HackEye-Models backlog).

## Status and next steps
1. **The user corrects masks** in the lab. Suggested start: the snow → water rule (surf, foam and glare); then the
   `lowconf` worst-first sort; then the rare surfaces (bike lane, pedestrian area, curb cut) with protect mode.
2. **Run `sync_lab_edits.py`** after editing sessions, before any training or Drive copy.
3. **Export:** the user names the export (e.g. `HackEye26.1.1-48`) once the corrections and the taxonomy are settled.
4. **Drive copy** of the master and/or export, on the user's go.
5. **Retrain** the app model on Vistas plus the export.
